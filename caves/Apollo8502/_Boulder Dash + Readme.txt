The game "Boulder Dash +" was distributed on one C64 disk.
One game with multiple sub-themes/games, in the following order:

- BDASH1
- BDASH '2'
- PROFESSIONAL
- TRIP TO HELL
- HEAVEN
- WILD WILLY
- ROCK BOTTOM
- RASKAPJE
- TOUGH TIMES
- KWADRUIF

Each sub-theme/game have 20 caves.
It's like BD1, but with an extra command (0xFE Raster) which differ from existing.
